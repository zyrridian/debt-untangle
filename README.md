# Debt Untangle

Debt Untangle helps groups keep track of shared expenses and understand who
owes whom.

## What it does

- Record expenses shared by multiple people.
- Track each person's contribution.
- Calculate balances between participants.
- See who needs to pay and who should receive money.
- Keep shared expenses organized in one place.

## Download

Download the latest Android APK from the app's
[GitHub Releases](https://github.com/zyrridian/debt-untangle/releases).

The APK published in this directory is the copy used by the public
[App registry](../../registry/apps.json).

## Development

This app is built with React Native and Expo.

Install dependencies:

```bash
npm ci
```

Generate the Android project:

```bash
npx expo prebuild --platform android
```

Run the Android development build:

```bash
npx expo run:android
```

## Release

The release workflow:

1. Builds the Android release APK.
2. Creates a GitHub Release.
3. Copies the APK and Android launcher icon to the registry.
4. Copies screenshots from `store/screenshots/`.
5. Generates `apps/debt-untangle/manifest.json`.
6. Regenerates `registry/apps.json`, including the APK SHA-256 checksum.
7. Pushes the updated registry files.

The current app identifier is `debt-untangle`. The display name can change
later without changing this registry path or identifier.

## Store files

The release workflow expects these files in the app repository:

```text
store/
└── screenshots/
```

The Android launcher icon is generated by Expo during prebuild and copied from
the generated Android resources. A separate store icon is not required.
